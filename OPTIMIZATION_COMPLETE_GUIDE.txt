================================================================================
TROUBLESHOOTING
================================================================================

If performance is still low:
1. Check thread pinning: htop should show all cores at 100%
2. Check for context switches: perf stat should show low cs count
3. Check cache misses: perf stat -e cache-misses should be <5%
4. Increase environments: --envs 256 or 512
5. Try dynamic scheduling: already enabled by default

If crashes occur:
1. Check memory: 256 envs needs ~2GB RAM
2. Reduce batch size if OOM: edit TD3Config.h
3. Check alignment: all buffers use AlignedVector32
